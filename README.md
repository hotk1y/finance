# Logotip. — Finance & Consultancy Landing

Одностраничный лендинг для консалтинговой компании Logotip.
Финансовый, экологический и бизнес-консалтинг.

## ✨ Возможности

- **Адаптивная вёрстка** — от 320px до широких десктопов
- **Тёмная / светлая тема** — переключатель в шапке, выбор сохраняется в `localStorage`
- **Прелоадер** с анимацией логотипа при загрузке страницы
- **Видео-блок** с кастомной кнопкой play и постером
- **FAQ-аккордеон** с центрированными карточками
- **Форма заявки** с валидацией полей
- **Подписка на рассылку** с проверкой email
- **Чат-виджет** с имитацией ответа оператора (заготовка для интеграции с реальным API)
- **Модальное окно Login / Register** с переключением вкладок и валидацией
- **Кнопки «Наверх» и «Чат»** — одинаковый стиль, вертикальный стек
- **Анимации появления** секций при прокрутке (`IntersectionObserver`)
- **Favicon** — SVG + PNG fallback
